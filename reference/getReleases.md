# Retrieve available database releases or versions of ENSEMBL

Retrieve available database releases or versions of ENSEMBL.

## Usage

``` r
getReleases(db = "ensembl")
```

## Arguments

- db:

  a character string specifying the database from which available
  resease versions shall be retrieved:

  - `db = "ensembl"`
