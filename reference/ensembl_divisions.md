# List all available ENSEMBL divisions

Retrieve a list of available databases on ENSEMBL for which
`get.ensembl.info` can be retrieved.

## Usage

``` r
ensembl_divisions()
```

## Author

Hajk-Georg Drost

## Examples

``` r
ensembl_divisions()
#> [1] "EnsemblVertebrates" "EnsemblPlants"      "EnsemblFungi"      
#> [4] "EnsemblMetazoa"     "EnsemblBacteria"    "EnsemblProtists"   
```
